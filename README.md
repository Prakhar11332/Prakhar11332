## ⌁ how I work

Every one of the projects above started the same way:

```
1. Learn    → understand the concept before touching the keyboard
2. Close    → shut the reference, rebuild from memory
3. Rebuild  → re-implement it myself, no copy-paste
4. Document → write it up for future-me, not just for a rubric
```

I'd rather ship something smaller that I can explain line-by-line than something bigger I copy-pasted my way through.
